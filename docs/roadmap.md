# First release

Organisations/projects, invitation-only Administrator/Viewer access, domain and
privacy rules, visit/bounce/activity measurement, configurable goals and rates,
protected CSV and six exact Insights chart families are implemented locally.
Compact storage and its offline upgrade/recovery tools preserve history. Guided
self-host setup, backup/restore and reproducible MIT source packaging are also
implemented and locally exercised. The team installation is live at
https://analytics.postdeploy.dev, and audited product source is public on GitHub.

Final acceptance adds runnable native HTTP checks in both layouts and guarded
read-only full-history probes, with bounded section progress streams for long
reads. See [operator acceptance](acceptance.md) for exact commands and limits and
[performance](performance.md) for measured results. Passing small fixtures does
not certify the initial 50-project/million-month/two-year workload universally.
Actual cardinality, visit/pulse rates, retention, fragmentation and remote limits
still govern an installation's usable envelope. All full organisation Insights
families and overview series/goals completed
individually in guarded offline reads, with exact table/CSV and known-population
reconciliation. Native full-corpus HTTP remains an environmental proof gap; no
silent timeout or partial total is accepted. Final source archives identify the
committed candidate and reproduce bytes; previous extracted installation evidence
is reused with unchanged dependencies and installer.

Retained physical evidence is 328,716,288 bytes for one million pageviews and
8,022,323,200 bytes for the two-year corpus plus preserved live trials. The latter
has 1,977,676,800 bytes below the decimal 10 GB hard ceiling, not a universal
storage margin. Eight GB was an engineering guide, not an accepted release SLA.
No automatic history shortening, approximate distincts or identity reduction.

Initial production provisioning/import and password login are verified on the
existing Workers Paid account. Remote restore/cutover, real Email, Free-plan
password CPU, deployed capacity and native window occlusion remain unverified.
Later scope: client
permissions/logins, public dashboards, scheduled/PDF reports, imports, payment
integrations, configurable funnels and MCP. Demo controls do not implement these.
